# Security Policy

## Supported Versions

This project is in early development. Security fixes are applied on active long-lived branches:
- `stable`
- `main`
- `dev`

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report privately to maintainers with:
- Affected component
- Reproduction steps
- Impact assessment
- Suggested mitigation (if available)

A response target is 72 hours for acknowledgement.
