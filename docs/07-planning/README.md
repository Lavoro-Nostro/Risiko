# Planning Docs

Use this folder for planning artifacts. For daily execution, use `WORK_TRACKING.md` at repo root.

## File Roles

- `roadmap.md`
  - Time-ordered implementation phases.
  - High-level scope movement only (not task-level status).
- `milestones.md`
  - Exit criteria per milestone.
- `backlog.md`
  - Prioritized feature/problem backlog grouped by `P0/P1/P2`.
- `risk-register.md`
  - Delivery and technical risk tracking with mitigation.
- `known-issues.md`
  - QA triage register (`KI-*`), repro-focused.

## Canonical Tracking Rule

- Program direction and ID model: `RISIKO_MASTER_PLAN.md`
- Active work status and owners: `WORK_TRACKING.md`
- QA issue details/repro: `docs/07-planning/known-issues.md`

Do not maintain competing status boards in multiple files.
