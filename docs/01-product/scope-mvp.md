# MVP Scope

## In Scope (P0)
- One classic map
- 2-6 players
- Reinforce / Attack / Fortify / End Turn
- Continent bonuses
- Real-time online multiplayer
- Local hotseat
- Basic map/UI feedback

## Out of Scope (for MVP)
- AI players
- Async mode
- Scenario editor
- Full custom rules editor
- Fog of war

## Exit Criteria
- Full match completion without desync
- Reconnect works during active match
- No client-authoritative gameplay logic
